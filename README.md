### Features

- **Fastboot & Hybrid ROM Flasher:** Automatic ROM detection and intelligent partition flashing.
- **AOSP Recovery Flasher:** Direct dual-slot (`vendor_boot_a` / `vendor_boot_b`) automated installer.
- **ADB Sideload:** High-speed ROM sideload manager straight from internal storage.
- **Universal Device Support:** Compatible with all Android smartphones via OTG.
- **100% Offline & Protected:** Zero external script dependencies during execution.
